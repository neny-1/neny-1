## 🚀 What I Build

### 🧠 Drosat AI Platform | Curriculum Intelligence & Agentic RAG

> Educational AI platform transforming Arabic textbooks into structured, interactive learning experiences.

**Live:** [drosat.com](https://drosat.com)

- Engineered a multi-stage curriculum ingestion pipeline combining native PDF extraction, OCR, and document structure resolution to process **500+ scanned Arabic textbooks**.
- Architected a decoupled dual-model inference pipeline using **Gemma 31B** for visual document understanding and **Qwen 27B** for reasoning, summarization, and assessment generation.
- Built asynchronous RAG pipelines for curriculum-grounded student Q&A, citation-backed answers, bilingual explanations, lesson summaries, and automated assessments.
- Implemented assessment generation across **14 canonical question formats**, supported by algorithmic minimum question requirements.
- Designed unified MongoDB and Qdrant storage with 20+ metadata fields per chunk.
- Implemented structured output validation using Pydantic, LaTeX validation, and LLM-as-a-Judge quality evaluation.

**Core Technologies:** Python, LLMs, RAG, OCR, VLM, Gemma, Qwen, Celery, MongoDB, Qdrant, Pydantic.

---

### 🔭 AiTech Safety Monitor | Real-Time Computer Vision

> Production Computer Vision platform for intelligent workplace safety monitoring.

**Product:** [AiTech Safety Monitor](https://aitech.net.au/solutions/aitech-safety-monitor)

- Architected a modular **7-plugin Computer Vision platform** processing 6+ concurrent camera streams at 15 FPS.
- Developed detection capabilities for PPE compliance, fire and smoke, occupancy monitoring, and dangerous-zone detection.
- Built real-time video streaming infrastructure using **WebRTC** and Redis message brokering.
- Integrated live camera feeds with a Vue.js frontend and violation notifications with a Laravel backend through webhooks.
- Evolved the architecture through Monolithic, Microkernel-based plugin, and Pub/Sub event-driven designs.

**Core Technologies:** Python, YOLO, Computer Vision, WebRTC, Redis, Docker, FastAPI, Vue.js, Laravel.

### 🤖 Universal Auto-Scraper | Agentic Web Automation

> An agentic web scraping framework combining autonomous browser exploration with deterministic extraction.

**Status:** In Development

- Designed an autonomous two-stage scraping agent using LLM tool calling to orchestrate **48+ Playwright browser tools**, explore dynamic websites, and generate reusable, verified selector blueprints.
- Engineered a programmatic extraction and replay pipeline using Scrapling, stealth HTTP sessions, cookie injection, and BeautifulSoup.
- Designed an agentic-to-deterministic workflow that separates intelligent website exploration from efficient, repeatable data extraction, eliminating recurring LLM inference costs during replay.

**Core Technologies:** Python, Playwright, Scrapling, BeautifulSoup, LLM Tool Calling, Agentic AI.
